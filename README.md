## Project Overview: 
Flow Tech Plumbing & Drains fixes the community, fixes blocked drains, fixes damaged kitchen sinks, and it has an online website which showcases how it operates. The website has a schedule which has an information of our working days. The prices of repairs.

The website will help our business grow, and get a wider reach of customers. From time to time we have specials that we advertise online so that our customers can save money for specials.
